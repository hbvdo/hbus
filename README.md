# Link Cloaker & URL Shortener

A custom, fast, and free URL shortener with OG Meta Tag Spoofing for dynamic link cloaking on social media platforms (Facebook, Twitter, WhatsApp, Telegram, Skype).

## Features
- **Dynamic OG Image Spoofing:** Custom preview images (Imgur, ImgBB, PostImages, or direct image URLs).
- **Bot Detection:** Serves meta-tags to social media scrapers while redirecting real users instantly.
- **Fast Storage:** Powered by Upstash Redis.
- **Zero Cost:** 100% free deployment via Vercel.

## Tech Stack
- **Frontend:** HTML5, Tailwind CSS
- **Backend:** Vercel Serverless Functions (Node.js)
- **Database:** Upstash Redis
